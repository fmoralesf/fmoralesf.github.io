Simuladores Educativos Interactivos

Convierte teoría en experiencias prácticas con IA
🎯 Meta: Salir con un archivo HTML funcionando que puedas usar en tus clases para que los estudiantes experimenten un concepto de tu disciplina.

Paso 1: Define Tu Concepto

Responde mentalmente estas 3 preguntas clave:

  • ¿Qué concepto quieres volver interactivo? (Ej: toma de decisiones, oferta/demanda, dilemas éticos)
  • ¿Qué decisiones tomarán los estudiantes? (2-3 variables que controlen)
  • ¿Qué resultados verán? (Consecuencias inmediatas de sus decisiones)

Paso 2: Prompt Maestro para Crear tu Simulador

Copia este template, personalízalo y pégalo en ChatGPT/Claude/Gemini:

Actúa como desarrollador web experto en simulaciones educativas. Crea un simulador interactivo para enseñar [TU CONCEPTO] a estudiantes de [TU ÁREA]. **ESPECIFICACIONES:** - Concepto: [Ej: "Toma de decisiones bajo incertidumbre en inversiones"] - Decisiones del estudiante: [Ej: "Monto a invertir, tipo de inversión, nivel de riesgo"] - Resultados: [Ej: "Ganancia/pérdida, feedback sobre la estrategia"] - Rondas: [Ej: "5 periodos de inversión"] - Insight esperado: [Ej: "Relación riesgo-rendimiento"] **REQUERIMIENTOS TÉCNICOS:** - UN solo archivo HTML autocontenido - HTML + CSS + JavaScript vanilla (sin librerías) - Funciona offline - Interfaz profesional y clara - Botón para exportar resumen final Crea el código completo.
💡 Clave: Mientras más específico seas, mejor será el resultado. No tengas miedo de ser detallado.

Ejemplos de Conceptos por Disciplina

Economía/Negocios

  • Simulador de mercado (oferta/demanda)
  • Decisiones de pricing
  • Gestión de inventario

Psicología

  • Dilemas éticos
  • Sesgos cognitivos

Educación

Ingeniería

  • Optimización de recursos

  • Trade-offs de diseño

Paso 3: Guarda y Prueba

  1. Copia todo el código HTML que te dé la IA
  2. Abre Bloc de Notas (Windows) o TextEdit (Mac)
  3. Pega el código
  4. Guarda como "mi_simulador.html"
  5. Abre haciendo doble clic
  6. Prueba todas las funciones

Prompts de Corrección Rápida

Si algo no funciona:

El simulador tiene un problema: [DESCRIBE EL ERROR]. Cuando [ACCIÓN], [QUÉ PASA]. Corrige el error y devuélveme el código HTML completo funcionando.

Para mejorarlo:

Mejora el simulador agregando: 1. [FUNCIONALIDAD QUE QUIERES] 2. [OTRA MEJORA] Mantén todo lo existente y devuélveme el código completo.

Para que se vea mejor:

Mejora el diseño visual para que se vea profesional y moderno. Usa colores atractivos y mejor tipografía. Mantén toda la funcionalidad.
